# v0.1.1

ContextDroid v0.1.1 is a Windows installer compatibility patch and documentation-focused release.

## Fixed

- Load `System.Net.Http` explicitly so the checksum-verifying installer works in Windows
  PowerShell 5.1 as well as current PowerShell.
- Add a Windows PowerShell 5.1 regression contract for the installer download path.

## Documentation

- Rework the README around a direct quick start, Android diagnostic coverage, the raw-first
  execution model, profile and output-mode comparisons, agent support, troubleshooting, and a
  documentation map.
- Clarify that installation URLs must be entered as raw terminal URLs rather than Markdown link
  syntax.

All release archives and installers are built from the exact `v0.1.1` tag, verified on their
native CI runners, checksumed, and published with the release manifest, notices, CycloneDX SBOM,
and build provenance.
