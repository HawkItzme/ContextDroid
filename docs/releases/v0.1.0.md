# v0.1.0

ContextDroid v0.1.0 is the first stable, directly installable release of the independently
maintained Android-focused RTK downstream.

It provides conservative Android Gradle, ADB, and bounded Logcat diagnostics while preserving
complete local raw output, original exit behavior, omission accounting, and confidence-based raw
fallback. The default `contextdroid-safe` profile leaves pipelines, redirects, structured and
binary output, security tools, broad discovery, and unknown commands untouched.

## Distribution and setup

- Checksum-verifying Linux, macOS, and Windows installers resolve GitHub's latest stable release by
  default; explicit version pins remain available.
- Release archives, DEB, RPM, CycloneDX SBOM, notices, release manifest, checksums, and build
  provenance are produced by the protected release workflow.
- `contextdroid setup detect` finds supported integrations without writing.
- `contextdroid setup preview` shows the complete proposed configuration.
- `contextdroid setup apply --yes` applies selected integrations transactionally with backups.
- `contextdroid setup status` and `contextdroid setup uninstall --yes` inspect or remove only
  ContextDroid-managed entries.

Claude Code on Linux is supported. Codex uses honest project guidance rather than transparent shell
interception. Cursor schema v1 remains experimental and requires `--include-experimental`.
The existing `contextdroid integrations` commands remain compatible throughout 0.1.x. There is no
`rtk` compatibility alias.

See the benchmark report for measured fixture results and limitations. Never share unredacted raw
logs.
